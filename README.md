# STC

Site for STC (Students' Technical Council) with home, team, events, and testimonials. Home also covers groups, features, and metrics.

Rishabh Gupta (RishabhGupta-04) built the group, event, and team cards.

## Run

```bash
git clone https://github.com/LifeAyush/stc.git
cd stc
npm install
npm start
```

Scripts from `package.json`:

- `npm start` — development server
- `npm run build` — production build
- `npm test` — tests
